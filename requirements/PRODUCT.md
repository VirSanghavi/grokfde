# Grok FDE — Product Vision

**Tagline:** Every prospect gets an engineer.

## Core idea

A technical company uploads everything its forward-deployed engineers or technical salespeople need to know (docs, APIs, pricing, security, MCP tools). Grok learns the company. The company gets a persistent AI Forward-Deployed Engineer.

This is NOT a documentation chatbot or generic sales bot. It behaves like:
- forward-deployed engineer
- solutions architect
- technical salesperson
- implementation engineer

Prospects interact through **chat**, **email**, and **live voice calls**. The FDE maintains **persistent memory across channels**.

## Magic moment

Prospect says in chat: *"We use Kubernetes on AWS."*
Five minutes later they press CALL.
Voice agent: *"Since you mentioned you're using Kubernetes on AWS..."*

## Demo narrative

Best demo is Grok FDE selling Grok FDE itself.
1. Upload product docs into knowledge base
2. Judge becomes prospect (Globex)
3. Chat with Atlas, mention stack
4. Click CALL — memory carries over
5. MCP tool / architecture generation
6. Feel: *"This isn't a chatbot. This is an employee."*

## Philosophy

- Modern, minimal, technical, expensive, fast, alive
- Developer-tool aesthetic (not CRM, not Intercom, not chatbot widget)
- Company surfaces: Dashboard, Knowledge, Conversations, Agent
- Prospect surfaces: Chat, Call, Rich technical artifacts
- **MAKE GROK'S WORK VISIBLE** — operational activity only, no chain-of-thought

## Ownership
